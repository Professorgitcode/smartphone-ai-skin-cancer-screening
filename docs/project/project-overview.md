# Smartphone-Based AI Skin Cancer Screening

## 1. Project Overview

The Smartphone-Based AI Skin Cancer Screening project aims to develop a mobile application that uses artificial intelligence to support preliminary skin lesion screening through smartphone images.

The application will allow users to select or capture an image of a skin lesion, submit the image for AI-assisted analysis, view the screening result, and receive appropriate guidance on seeking further medical assessment.

The application is intended to support screening awareness and access to preliminary assessment. It is not intended to replace qualified healthcare professionals, clinical examinations, or diagnostic procedures.

## 2. Problem Statement

Access to timely skin lesion assessment can be limited by factors such as geographical distance, financial constraints, and limited availability of healthcare services.

A smartphone-based screening application could provide an accessible way to submit skin images for preliminary AI-assisted assessment and encourage users to seek appropriate clinical care.

The reliability and clinical usefulness of such a system depend on the AI model, image quality, validation, and responsible presentation of results.

## 3. Project Aim

To develop a smartphone application that supports preliminary skin lesion screening using AI-assisted image analysis and provides users with appropriate follow-up guidance.

## 4. Intended Users

- Individuals seeking preliminary information about skin lesions.
- Healthcare practitioners evaluating the application as a potential screening-support tool.
- Project demonstrators and evaluators using synthetic demonstration data.
- Developers and researchers evaluating the application's technical implementation.

## 5. Target Platform

The initial development target is Android.

The application will be developed using Flutter and Dart on Ubuntu Linux. Other platforms may be considered later, depending on project requirements and available resources.

## 6. Core Application Workflow

1. Open the application.
2. Select an image source.
3. Capture a photograph or select an existing image.
4. Preview the selected image.
5. Submit the image for screening.
6. Display the screening result when analysis is available.
7. Present appropriate follow-up guidance.
8. Allow the user to begin another screening.

## 7. Proposed Technology Stack

- **Mobile framework:** Flutter
- **Programming language:** Dart
- **Development operating system:** Ubuntu Linux
- **Version control:** Git
- **Source-code hosting:** GitHub
- **AI inference:** To be determined after confirming the model and integration requirements with the machine-learning team.

## 8. Project Status

The Flutter development environment has been configured, the default application has been run on an Android emulator, and the initial project has been committed to Git and pushed to a public GitHub repository.

Application architecture, interface implementation, screening integration, and testing remain ongoing development activities.
